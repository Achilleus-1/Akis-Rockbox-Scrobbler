# Aki's Rockbox Scrobbler 1.1.1

Standalone native desktop app with remembered dark mode for Windows 10/11 x64.

This packaging update adds license texts for OpenSSL, libffi, zlib, bzip2,
liblzma and libmpdec from Python's runtime, and records the runtime versions
inside the release's licenses folder. Bundled-app verification now checks that
these notices are present. The app's scrobbling behavior is unchanged.

Choose `*-setup.exe` for normal installation, or extract the entire
`*-portable.zip` and run the EXE. No system Python or FFmpeg is needed.
`*-source.zip` contains developer source. `SHA256SUMS.txt` verifies the downloads.

The app preserves existing queues and duplicate protection. Last.fm connection
requires internet and your own API key/shared secret. Executables are unsigned.
