The Frutiger Aero music desk returns as a standalone native Windows app.

- Restored pastel cyan, lavender and mint scenery, flowing ribbons, rounded glass cards, deep teal sidebar and glossy pocket-player artwork.
- Ported the original liquid glass shaders to native OpenGL: animated refraction, edge dispersion, pointer reflections and click ripples.
- Added matching dark mode, remembered live/still glass, reduced-motion support and a still graphics fallback.
- EXE is the primary launcher. Setup installs shortcuts; portable downloads run the included EXE. Building source creates `Akis-Rockbox-Scrobbler.exe` directly in the project folder.
- Qt/Python are bundled privately. No browser runtime, separate Python install, FFmpeg or local server is needed.
- Restored file dropping and a safe sample preview. Existing queue, receipts and saved preferences are preserved.

Choose the **windows-x64-setup.exe** for a normal Windows 10/11 installation, or extract the entire **windows-x64-portable.zip** and run its EXE. Keep `_internal` with the portable EXE. Source ZIPs require the documented build step. Downloads include dependency licenses and SHA-256 checksums.

Validation: 45 backend/native-widget tests, real OpenGL checks for animation/pointer/ripple/dark output, and portable/installed EXE smoke checks without system Python. Live glass requires OpenGL 2.1+; unsupported graphics retain the still Aero interface.
