# Aki's Rockbox Scrobbler 1.1.0

A standalone native desktop app for Windows 10/11 x64, with remembered dark mode.

- Replaces the browser interface and local HTTP server with a native Tk/ttk window.
- Adds light/dark themes across the queue, settings and reading panels.
- Includes normal Setup and portable downloads with a private Python/Tcl/Tk runtime. No Python or FFmpeg installation required.
- Preserves the existing queue, remembered credentials and account-specific duplicate receipts in `%LOCALAPPDATA%\RockboxRelay`.
- Keeps explicit selection, destination/date confirmation, clock correction, old-date handling and interrupted-result review.

Choose `*-setup.exe` for normal installation or extract the entire `*-portable.zip`. `*-source.zip` is for developers. `SHA256SUMS.txt` verifies the downloads. The EXEs are unsigned. The browser opens for Last.fm authorization/external links; the app requires your own Last.fm API key and shared secret.

The previous WebGL decoration is replaced by a static native Aero-inspired desktop design. User data remains separate from the application and is preserved on uninstall.
